# DeFi Labs Navigator — как это работает

Простая схема:

1. **Google Таблица** — ты правишь / смотришь данные (листы `ethereum`, `bitcoin`, `БИТВА ПУЛОВ RWA`, таблица с **A1**).
2. **Apps Script** — читает таблицу и отдаёт JSON на сайт; по желанию синхронизирует RWA с Jupiter.
3. **Сайт** — после входа VIP тянет JSON с Apps Script; проценты и период **досчитывает сам**, если в ячейке доля (0,18 → 18%).

**Vercel ничего настраивать не нужно** — только деплой сайта с GitHub.

## 2. Apps Script (один раз после правок кода)

1. [script.google.com](https://script.google.com) → проект навигатора.
2. Вставь **весь** `DeFi-Labs-Navigator-AppsScript.js`.
3. **Развёртывание → Управление → Изменить → Новая версия → Развернуть** (доступ: «Все»).
4. URL `/exec` должен совпадать с `DATA_API_URL` в `index.html` (уже стоит).

Меню **DeFi Navigator** на листе RWA: синх Jupiter, авто-синх раз в час.

Ключ Jupiter (один раз, если уже создавали на portal.jup.ag): **Apps Script → Настройки проекта → Свойства скрипта** → `JUPITER_API_KEY` = ваш ключ. Либо вставьте тот же ключ в **Z4** → меню **«Запомнить Jupiter ключ из Z4»**. В GitHub ключ не хранится.

---

## 3. Сайт

Пуш в `main` → Vercel сам обновится. На сайте **↻ Обновить**.

Вход VIP — как раньше (PythonAnywhere). **Данные** — только из Apps Script / таблицы.

Проверка в браузере (F12 → Console): после загрузки `apiVersion: 4`, RWA ≈ 8 позиций.

---

## Колонки APY / fee

- **APY** — колонка **APY**, не APR. В ячейке можно `18,65%` или доля `0,1865` — сайт покажет **18,7%**.
- **fee_tier** — `0,30%` или `0,003` — сайт покажет **0,3%**.
- **Период** — из «Дата открытия» или из поля period; «2505 дн» игнорируется.
