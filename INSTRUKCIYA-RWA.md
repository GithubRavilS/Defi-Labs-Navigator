# RWA — что сделать один раз (2–3 минуты)

Всё остальное уже в коде: лист **«Битва пуллов RWA»**, категория **rwa** на сайте, синхронизация Jupiter **бесплатно** (без платных тарифов).

---

## Шаг 1. Google Таблица

1. Открой таблицу DeFi Labs Navigator (та же, что для ETH/BTC).
2. Лист **«Битва пуллов RWA»** (если видишь два похожих — оставь один, второй удали).
3. Ячейка **B6** — вставь ссылку на портфель, например:  
   `https://jup.ag/portfolio/ТВОЙ_SOLANA_АДРЕС`
4. Строка **7** — шапка `name | apy | period | status | link | description | pair` (уже должна быть).

Ниже строки 8+ скрипт заполнит сам (как «битва пуллов» на bitcoin: основной блок + блок деталей справа).

---

## Шаг 2. Google Apps Script (обязательно)

1. [script.google.com](https://script.google.com) → проект навигатора.
2. Замени весь код файлом **`DeFi-Labs-Navigator-AppsScript.js`** из репозитория.
3. **Развёртывание → Управление развёртываниями → Изменить → Новая версия → Развернуть**  
   (без этого сайт не увидит RWA-синх).

**API:** платить ничего не нужно. Jupiter отдаёт данные **бесплатно** без ключа (для нашего режима «раз в час» этого хватает).  
Если когда-нибудь будет ошибка 401 — на [portal.jup.ag](https://portal.jup.ag/) план **Free ($0)** → ключ в **Project Settings → Script properties** → `JUPITER_API_KEY`.

---

## Шаг 3. Один клик в таблице

После открытия таблицы появится меню **DeFi Navigator**:

1. **Синхронизировать RWA (Jupiter)** — проверка сразу.
2. **Авто-синх RWA каждый час** — включить один раз.

Дальше таблица и сайт обновляются сами (сайт — кнопка **↻ Обновить**).

---

## Шаг 4. GitHub / Vercel

Репозиторий: **https://github.com/GithubRavilS/Defi-Labs-Navigator** — пуш в `main`, Vercel подтянет деплой сам.

## Проверка

- На листе после синха: строки Raydium / Orca / пары USDC–BTC и т.д., **без** Kamino Lending.
- На сайте: категория **RWA · Solana (Jupiter)**, карточки как у ETH/BTC (битва пуллов).
